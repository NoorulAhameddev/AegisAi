# Code of Conduct

This project follows the standards in [docs/governance/CODE_OF_CONDUCT.md](docs/governance/CODE_OF_CONDUCT.md).

By participating, you agree to:
- Treat everyone with respect and professionalism.
- Provide constructive feedback and avoid harassment or discrimination.
- Follow maintainer guidance if conflicts arise.

For any conduct concerns, follow the reporting process outlined in the linked document.
