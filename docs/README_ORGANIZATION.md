# Project Organization (2026-01-27)

- All scripts are in the scripts/ directory.
- Documentation is in docs/.
- Test files are in tests/.
- Configuration files are at the root.
- Obsolete/archived files are in archive/ or legacy/.
- uploads/ and data/ are git-ignored.
- Naming is standardized to kebab-case or camelCase.

See .gitignore for details on ignored folders.
