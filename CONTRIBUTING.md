# Contributing

Please read the full guidelines in [docs/governance/CONTRIBUTING.md](docs/governance/CONTRIBUTING.md) before opening a pull request.

Quick checklist:
- Use feature branches (`feature/*`, `bugfix/*`, `chore/*`).
- Run `npm run lint` and `npm test` (or the CI equivalents) before pushing.
- Follow the PR template and keep changes scoped.
- Add/update tests and documentation when you change behavior.
